# 十一代差距清单与自迭代记录（issue #23）

唯一验收标准 = 目标样张 `review/reference/target-ref.jpg`。基线 = 十代成品
（`delivery/batch/r10-*.png`，配方 `delivery/recipe.md` 十代固化版）。
对比方法：样张裁出壁纸区（1020x2225）与十代成品 1440x3200 等比并排 + 关键区域（面部/描边/泡泡/沙地）2–3x 放大并排。

## 0. 第一步自评差距（十代 vs 样张，按对观感影响从大到小）

| # | 维度 | 差距（具体到可执行） | 影响 |
|---|---|---|---|
| G1 | 构图与留白（角色排布） | 样张角色**前后叠压成一簇竖排群像**（珊迪→派大星→章鱼哥→蟹老板+海绵宝宝→小蜗 依次叠压，相邻身体接触明显）；十代 12 张全部是**一字并列站**，相邻角色间距 150–400px、零接触 → 观感是"贴纸排队"不是"群像" | 最大 |
| G2 | 画风-背景（沙地） | 样张=角色脚下的**聚拢沙岛**（岛宽约画面 0.7，深色描边完整可见、两侧不到画缘）；十代=通栏横带 → 无"岛"感、画面底部像割了一刀 | 大 |
| G3 | 配色还原（海绵宝宝） | 样张身体=高饱和**纯黄**、气孔=橄榄绿小椭圆（不规则、偏小）；十代=**淡黄绿**身体 + 大颗亮绿圆斑 + 外缘一圈**浅绿描边晕**（LoRA 漂移）+ 灰白眼球/灰衬衫 → 整体发灰发绿、不够"官方黄" | 大 |
| G4 | 画风-背景（泡泡） | 样张泡泡=**白色大圆环**（直径 ≈60–190px@3200）集中在角色周围、环内有弧高光；十代=大量 4–8px 小点铺满全画面 → "脏"、没有泡泡感 | 大 |
| G5 | 角色造型（珊迪头盔） | 样张头盔=**扁平透明罩**（背景直接透出）+ 白色单线圈 + 小弧高光，且**盔圈左上方别一朵粉花**（橙心）；十代=灰半透明穹顶填充+大白高光块（3D 玻璃感）、无花 | 中大 |
| G6 | 表情生动度 | 样张全员**大张嘴笑**（露齿+露舌+深红口腔、眉形上扬夸张）；十代珊迪/海绵宝宝偏抿嘴或小张嘴、无舌头，派大星眉毛偏淡 → 偏"呆" | 中 |
| G7 | 互动自然度 | 样张角色有身体倚靠+共同焦点+泡泡穿过；十代有视线关联+泡泡带但**无身体接触** → 基线禁道具，此项只能靠叠压+间距收紧+泡泡穿过改善 | 中 |
| G8 | 画风-背景（花朵） | 样张花朵轮廓**描边粗（约 14–18px@1440）且有笔触感**、瓣环圆鼓；十代线条细而均匀（≈8px）→ 背景比角色"素"，精致度不足 | 中小 |
| G9 | 线条干净度 | 样张描边粗黑均匀、干脆；十代描边偏细偏软（0.5–0.85x 缩小贴入致线宽收窄+AA），派大星描边凹角内侧有少量红色 AA 残屑（既有 C4 口径内） | 小 |
| G10 | 整体完成度 | 样张=官方海报质感；十代=拼贴感（由 G1/G2/G3/G4 汇聚而来） | 随上收敛 |

> 不受差距清单影响的基线项（不退步）：≤3 角色、肢体完整、无道具无文字、1440x3200、
> 小尺寸档（§4.2 九代新档）、C5 留白（顶部 ≥50% 线）。样张本身是 8+ 人群像且角色顶部更高，
> 十一代在"≤3 角色 + 小档 + 留白"约束内**最大化簇密度与叠压**来逼近其群像感。

## 2. 迭代记录

- **R1（构图/背景层）**：新 SCENES11（簇心收拢+后排上站台+边缘叠压）、沙岛（rx520/ry330 扁椭圆、
  顶缘≈2500）、场泡/泡泡带改样张档大圆环（新增 `draw_bubbles11`：既有 `draw_bubbles` 在 RGBA
  画布上直接绘制时 PIL 是替换像素而非 alpha 混合，大泡泡会变成不透明浅盘——样张泡泡内部应透出
  背景，此为十一代发现并修复的管线缺陷）、花朵描边加粗。出 b01/b03/b07 与样张并排比：
  群像感、沙岛、泡泡、底色立即向样张靠拢；剩余集中在海绵宝宝配色（R2）与珊迪头盔/表情（R3）。
- **R2（海绵宝宝调色）**：`sb_palette.py` 四步（官黄/橄榄气孔/外缘灰晕回描边黑/灰白提纯白，
  颜色锚点采样自样张）。b01 实测 body=58613、pore=15416、halo=3671、whites=1516 px 回色，
  身体黄、气孔、描边干净度均与样张同档；外缘"浅绿描边晕"根因查明 = RMBG 灰白 AA 边贴深绿底
  呈色，非 LoRA 绿晕，回描边黑同时兼得样张的粗描边观感。新出 3 个露舌种子
  （sb-right11 20263021–23）逐张过 §5 单元审计全部不采用（头身分离/头身比失衡/跳跃步态），
  维持七代胜出单元 sb_r + 调色。残留：海绵宝宝嘴内无舌（样张有）——单元级特征、种子成本
  不成比例，列为接受项。
- **R3（珊迪换单元 + 盔圈粉花）**：`gen-round11.py` 新增 transparent-dome + 露齿露舌 prompt，
  cheer11 出 4 种子、left11 出 3 种子，按 §5 单元审计（含硬闸B 盔圈闭合）选
  20263004（cheer：白圈粗而闭合、大张嘴露舌）与 20263013（left：露齿露舌大笑、挥手）。
  两粒种子各带亮红小球（cheer 悬盔圈外、left 骑盔圈线）：`clean_sandy_ball` 按环带像素
  逐层回填+透明化，盔圈保持闭合；`draw_helmet_flower` 在盔圈左上方程序绘制样张同款粉花
  （角色标志装饰，非道具）。b03/b07/b10/b12 泡泡带绕行路线修正，避免与盔圈圆环同心相碰。
- **R4（成品级皮肤必检口径，§4.4）**：b07 检出 3 个 4–6px 残留红岛，排查出两类机制：
  ① 贴入 LANCZOS 缩放后派大星描边×白色衣物交界的红色 AA 小岛（被皮肤围合、不贴黑线，
  十代口径未覆盖）；② **假阳性**——十一代新珊迪更大更低的舌头恰好被派大星审计裁切框罩住，
  口腔红碎块被粉色舌面围合、命中皮肤红点判据（红岛实际位于珊迪嘴上、不在派大星身上）。
  统一处理：检测限定在**派大星贴入 footprint 掩膜**内，检出即按环带肤色中位回填、复检归 0
  后存档（`patrick_postclean`，十代"皮肤红点 0"结论不回退，固定流程可复现）。
- **终态自评（对样张）**：**12/12 全合格（通过率 100%，见 manifest-round11.md）**。
  G1 簇状叠压达成（身体接触、前后层次、样张式竖排）；G2 沙岛同形；
  G3 配色同档（残留：SB 无舌、珊迪 cheer 眼无睫毛——小图不可辨）；G4 大圆环泡泡同档；
  G5 透明盔+白圈+粉花达成（粉花改坐盔圈 10–11 点弧位、泡泡带避让；残留：left11 盔圈淡蓝
  vs 样张白，小尺寸下不可辨）；G6 表情生动度大幅提升（珊迪露齿露舌大笑；SB 微笑无舌为接受项）；
  G7 视线+叠压+泡泡穿过；G8 花朵粗描边；G9 描边回色后更粗更接近样张。
  **与样张仍存的结构性差距**：样张为 8+ 角色密集竖排群像、人物占中部主体；底线限定 ≤3 角色，
  中部密度天然低于样张——在 3 角色约束内已最大化簇密度与样张化程度。
  剩余差距均为"小尺寸下不可辨"或"角色数约束"级。
