## 1. 海绵宝宝腿身比（任务 1）

口径：**腿(裤腰带顶→脚底) / 身(头顶→裤腰带顶)**，`sb_proportion.leg_ratio` 程序测量
（棕色短裤带=裤腰，内容底行=脚底；alpha/背景色双模式，腰带按棕带计数峰值 45% 定位，全流程
原图/调色后/裁后三态读数一致）。

| 对象 | 实测腿身比 | 说明 |
|---|---|---|
| 官方经典立绘（5 幅，`assets/spongebob-png/`） | 0.544 / 0.586 / 0.591 / 0.601 / **0.669**(宽块) | 官方比例实证带 **[0.54, 0.70]**；宽块画风（样张同款）≈0.67–0.70 |
| 官方并排立绘 SB（077320） | 0.697 | 窄体新画风，同样落带内 |
| 样张海绵宝宝 | ≈0.62（±0.12） | 腿部被报纸遮挡：头顶 1410、裤腰 ~1710（领带尖 1690 以下被遮），按站位地面线 ~1900 反推 |
| **七/十一代在用单元**（g7cut spongebob-c1_00001） | **1.34** | ≈官方 2 倍——「腿太长」投诉实锤 |
| 十二代单元 20263101（出图原值） | 0.752 | prompt 加短腿约束后 8 种子中过单元审计的最优者 |
| **十二代在用单元（手术修正后）** | **0.680** | `shorten_legs` 在小腿区缝合 51 行，=官方宽块实测值 |

**腿在哪一环被拉长**：贴入环节排除——`paste_figure` 为等比缩放（compose-round8.py:295–301），
不改变任何身体比例；拉长发生在**单元出图**（prompt 无腿长约束 + LoRA 长腿先验；
十一代 sb-right11 三种子即因「头身比失衡」全部弃用，但没有程序闸把关）。

**修正方法（双保险 + 硬闸）**：① `gen-round12.py` prompt 显式加入
`short thin legs, proportionally small legs, tall rectangular sponge body` + 负面 `long legs, big feet`，
种子 20263101 过 §5 单元级必检（双臂双手四指、恰好两鞋、视线朝右、露齿笑）；② 生成后 0.752
仍略超带宽，由 `sb_proportion.shorten_legs` 确定性缝合至 **0.68**；③ 合成前**硬闸C**
（腿身比 ∈ [0.55, 0.75]，`compose-round12.py` 代码强制，越闸 `SystemExit` 拒绝合成）——
此即配方固化的 **SB 单元腿身比硬口径**。
