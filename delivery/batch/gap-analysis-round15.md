# 十五代差距清单（issue #31）

唯一验收标准 = 度假泳圈样张 `review/reference/swim-ref.jpg`（比奇堡群鱼度假图）。
基线 = 十四代最好成品 `delivery/batch/wp-shallow-rings-2k.png`（r14-swim-rings-v5）。
整幅并排 `cmp15-full.png`，关键区放大并排 `z1-pose / z2-props / z3-light`。

## 差距项（差在哪 → 为什么差 → 怎么修）

### D1 入圈姿态：半身直立 vs 全身瘫坐
- **差在哪**：样张三条鱼都是**全身瘫在圈里**——臀部坐进圈内、躯干后仰带侧倾、双腿前伸
  搭在圈前缘（绿鱼双腿完全可见、松弛弯曲；黄鱼翘腿交叠；白袍鱼黑鞋交叠压在前缘管上）、
  一臂搭在圈管上。十四代只有**腰线以上**：胯下截断藏进前缘，观感是「扶着圈站着」，
  且手臂高举挥舞、表情亢奋，没有「瘫」的松弛感。
- **为什么差**：十四代单元=站姿生成 + 腰部锚定截断（路线一圈层三明治），物理上就不可能
  出现搭在圈前缘的腿；姿态模板也是站姿挥手的「见客表情」。
- **怎么修**：单元姿态改为**全身瘫坐**（slumped sit：后仰、双腿前伸/交叠、手搭圈管），
  且腿必须**画出来压在圈前缘之上**（z 序：背景→躯干→圈前缘→腿）。走 B 路线则由
  分区重绘直接画出「坐在圈里」的全身，姿态天花板最高。

### D2 度假叙事：无道具 vs 道具构成情节
- **差在哪**：样张有墨镜（黄鱼戴在脸上）、ZZ 状态符号、橙汁杯（冰块+吸管+橙片）、
  椰子（吸管）、粉花环；每个角色一个「度假状态」。十四代空手、无任何叙事道具。
- **为什么差**：十四代硬口径「无道具」，配方也规定道具全部程序绘制、从未做过手持道具。
- **怎么修**：按样张词汇表分给三角色：海绵宝宝=墨镜+ZZ（打盹）、派大星=橙汁杯、
  珊迪=粉花环。走 A 路线道具须与单元同出或程序绘制（手绘感难保证）；走 B 路线道具
  直接随分区一起「画」出来，手-杯/手-椰子的握持关系才自然（样张的手物交互正是贴入
  路线最难补的一环）。

### D3 画风统一：贴上去的 vs 画进场景的
- **差在哪**：样张角色与背景共用一套手绘笔触和落日光色——角色身上有环境 teal/暖金回染，
  描边是深色但带色、边缘柔化；圈是**简单平涂条纹**（红白/蓝白），阴影极简。
  十四代背景是写实质感高频细节（水纹/云），圈是亮面印花泳圈；角色是亮平涂+硬黑描边，
  光色与场景脱节，边缘有贴入感（白边/硬轮廓）。
- **为什么差**：十四代背景为 illustrious 图生图写实档，角色单元是白底 LoRA 生成，
  合成时只做了 8.5% 向暖混色 + 水回染，不足以统一笔触与光色。
- **怎么修**：B 路线：以样张为底做**逐角色分区重绘**（背景像素零改动，denoise 只作用于
  角色区），光色/笔触天然统一，圈保持样张平涂条纹。A 路线兜底：程序绘制样张档
  平涂条纹圈背景 + 色温浸染/light-wrap/边缘柔化，仍难补笔触级统一。

### D4 场景氛围元素缺失（次要）
- **差在哪**：样张海面有落日反光带与星芒、水面漂浮海星、水下鱼影、沙滩心形；
  十四代背景有海星/贝壳但无落日反光带与心形，整体偏冷。
- **为什么差**：背景来源不同（写实沙滩 vs 样张浅金落日海面）。
- **怎么修**：B 路线天然继承（样张底像素保留）；A 路线需重绘背景，等于重做十四代。

## 路线判定（先小规模试跑，见 route-test/）
- **B 整图分区重绘**：背景=样张本身，鱼→角色逐区 inpaint（单角色单次，避免多角色
  互串）。风险=分区去形（鱼形残留）、LoRA 身份保持、腿身比可控性。→ 实测见
  `route-test/` 与 recipe 十五代节。
- **A 单元贴入+光影融合**：全身瘫坐单元 + 腿压前缘 z 序 + 色温浸染/light-wrap。
  光影与笔触统一是天花板（D3 修不到样张水平）。
