## 0. 管线总览（为什么是这条线）

```
① 逐角色单元出图（illustriousXL + 角色专属 LoRA，单人白底）
② RMBG-2.0 抠图 + alpha 收紧          → 无白色 halo
③ 程序绘制官方图案背景（bg-flat11.py）  → 样式 100% 可控、无 AI 伪影（十一代：花形描边加粗向样张靠拢）
④ 合成（compose-round12.py）：定向回色/清斑/调色 → 簇状叠压贴入 → 盔圈粉花 → 样张档泡泡带串视线
⑤ 按 C1–C5 + 硬闸A/B/C 逐张审（关键区域 100% 放大复核；派大星皮肤红岛成品级回填复检，见 §4.4）
```

要点：**风格与构图靠程序保证，角色质量靠“单人小场景 + 种子选优”保证。**
多角色直接同框文生图在五代前已被否决（属性互串：粉头、绿箭头、海绵块手——七代复验仍复现，见 PR #16），
因此每个角色单独生成、单独审、再程序合成；画面里唯一“画”出来的是角色单元，背景与互动道具全部程序绘制。

## 1. 角色单元出图（工作流 + 采样参数）

ComfyUI 图结构（同 `gen-round8.py`，亦即 gen-round7.py 的模板化）：

| 节点 | 参数 | 为什么 |
|---|---|---|
| CheckpointLoaderSimple | `illustriousXL_v01.safetensors` | 官方 2D 卡通风的底模；Qwen 线（写实、全员合影）已停用于本线 |
| CLIPSetLastLayer | `stop_at_clip_layer = -2` | 掉最后一级，解锁 Illustrious 系风格词表达（sd-scripts 同款约定） |
| LoraLoader | 角色 LoRA，见 §2 | 每角色专属 LoRA，杜绝跨角色属性互串 |
| CLIPTextEncode(正) | 模板见 §1.1 | |
| CLIPTextEncode(负) | 模板见 §1.2 | 肢体缺陷负面清单是 C3 的一层保险 |
| EmptySD3LatentImage | **1024 x 1536** | 出图分辨率必须 ≥ 贴入尺寸（见 §4 不放大规则）。六代海绵宝宝按 832 出图、2.1x 放大贴入 → 发软+肢体崩；七代提到 1024x1536 后 0.62x 缩小贴入，全分辨率锐利 |

每角色每姿态出 3–5 个 seed，逐张过 §5 单元审计后**只选 1 个干净种子**进入合成。选优不省：
七代海绵宝宝试了 22 个 seed 才命中；跳过审计直接批量贴入会把废件带进成品。

### 1.1 正面 prompt 模板

```
<角色触发词>, <角色体貌特征词>, <姿态短语>, <方向短语>,
full body with margin around, nothing cropped,
flat 2d cartoon, tv cartoon style, clean lineart, simple shading, solo, simple white background
```

- **姿态短语（海绵宝宝，七代胜出模板）**：`standing on the ground, both feet on the ground, exactly two shoes, arms relaxed slightly away from body, open hands with four spread fingers, happy smile`
  —— 双臂离身 + 手掌张开 + 四指，直接对症六代“团块拳”；“exactly two shoes”对症三只鞋伪影。
- **方向短语**：`looking to the left|right` —— 视线方向必须朝向对手角色，这是 C2 叙事关联的锚（视线链）。
- **`solo` + `simple white background`**：单人、纯色底 → 抠图干净、不带入背景杂物。
- 海绵宝宝特征词（sbpilot 训练 caption 原词，照抄）：`yellow porous sponge, square body, big blue eyes, buck teeth, white shirt, red tie, brown shorts, red striped socks, black shoes`。

## 3. 抠图（RMBG-2.0）+ alpha 收紧

- ComfyUI `RMBG` 节点：`model=RMBG-2.0, process_res=1024, sensitivity=1.0, mask_blur=0, mask_offset=0`，输出 Alpha。
- 后处理 `tighten_alpha(floor=115, erode=2)`：alpha 低于 115 截断、再收缩 2px —— 消除白底渗出的白色 halo（三/四代 halo 教训）。
- 抠图后按 bbox 裁到内容包围盒，贴入比例以**裁剪后高度**为分母计算。

## 4. 背景与合成

### 4.1 官方图案背景（`bg-flat11.py`，程序绘制，非生成）

- 底色深绿 `(64,99,43)`、沙地 `(216,196,140)`、沙地描边 `(88,104,44)`——全部采样自样张 `target-ref.jpg`。
- 花朵云形轮廓 11 朵沿边缘与上半部排布（样张同款位置、6 色、高斯腐蚀描边不产生凹角伪影），中部角色区留空；
  **十一代描边加粗（R*0.085→R*0.12、alpha 235→250）向样张的粗笔触轮廓靠拢（G8）**。
- **沙地为"聚拢沙岛"而非通栏横带（G2，十一代）**：合成层绘制椭圆 cx720/cy2830/rx520/ry330
  （顶缘≈2500、完整下缘、两侧不到画缘），与样张角色脚下沙岛同形；深绿底+花纹在岛屿四周露出。
- **泡泡一律画在独立 overlay 层再 alpha_composite（`draw_bubbles11`）**：PIL ImageDraw 直接画在
  RGBA 画布上是替换像素而非 alpha 混合，泡泡内部会呈不透明浅盘；样张泡泡内部透出背景
  （十一代发现并修复的管线缺陷）。场泡 ~10 个、大圆环 r25–90 + 左上弧高光，聚于角色簇上方两侧（G4）。
- **背景直接画在 1440x3200 画布上**，成品原生 1440x3200，**全程无放大环节**（C4 的分辨率保证来自这里，不走 Remacri）。

### 4.2 贴入规则（C3“别放大过度”的硬约束）

- **贴入比 = 贴入高 / 单元裁后高 ≤ 1.0x，只允许缩小贴入**（“裁后高”= alpha 收紧并 bbox 裁剪后的单元高度；`compose-round9.py` 逐角色打印该比值并写 `paste-report.json`，审计报告核对）。
  原因：放大贴入是六代海绵宝宝“发软 + 肢体崩”的直接诱因；缩小贴入等于超采样，线条只增不减。
  （注：七代 manifest 写的 0.62x 是按未裁全高 1300px 口径；按本配方统一口径，七代胜出单元实测 ≈0.93x，同样 ≤1.0x。口径以本配方为准。）
- **九代新尺寸档（issue #19 按样张标定）**：八代批量“角色顶在下半屏、整体偏大”，对照样张实测——样张为堆叠群像，
  单体角色高度多在画面 21%–28% 档（约 670–830px@3200），而八代主角 25%–36%；故在八代官方比例基础上
  **全角色统一下调一档（×0.76）**，向样张占比靠拢且更疏朗。~~各角色间官方相对比例不变~~
  ——十一代表沿用此名义；十二代按样张逐角色实测**重建了相对比例**（见下），SB 基线档不变。

- **十二代相对高度表（issue #25 按样张重建，SB=1.0）**：九代表沿用「官方相对比例」名义，但十二代
  以样张逐角色实测重建后发现三处长期错配——派大星偏小（样张 1.52±0.10、官方并排图 1.43，旧档仅 1.22）、

- **站位/倾角（十一代簇状群像，G1/G7）**：样张的观感核心是**前后叠压的竖排群像**而非一字并列。
  SCENES11（`compose-round11.py`）三原则：① 簇心收拢——同景角色 cx 间距收到 ~280–360（十代 500+），
  身体边缘自然叠压 60–160px（只叠体侧/手臂，主要肢体保持可辨，C3 不违）；② 后排上站台——
  后排 `ground_y≈2470–2560`（脚落沙岛顶缘）、前排 `2760–2880`、小蜗前景 `2950+`，头顶高度错开；
  ③ z 序显式：表内顺序=贴入顺序=后→前，后排先贴被前排压住，形成样张式堆叠。±3–5° 倾角制造动势。
- **C2 互动靠三件事**：① 视线方向（各单元生成时用 looking-to 对齐对手）；② **身体叠压**与间距
  （簇状围合，十一代起不再是"并列+泡泡"）；③ 泡泡带——overlay 层样张档大圆环+左上弧高光，
  从一侧角色升起、掠过中间角色头顶、落到另一侧，串起视线链；**路线避开盔圈圆环**，
  避免同心相碰（十一代实测修正）。**除泡泡外不加任何道具**（C4 防怪道具）。

1. `clean_patrick_blue`：短裤蓝色彩条/花形孤岛（Patrick_il 属性泄漏）→ 局部面板色调和扩散回填；

3. `clean_patrick_skin`（十代新增，issue #21）：粉色皮肤上散落的暗红小点（Patrick_il 红色素泄漏/数据伪影，
   与 1/2/4 同源）→ 逐孤岛回填为周围肤色：在皮肤区内取「红度明显高于本图肤色中位数（动态阈值
   `R−G > 肤色中位差+12` 且 `G < 肤色中位−18`）、面积 ≤400px、外围环带 ≥75% 为皮肤」的异常红孤岛，
   以其环带肤色中位数 + 高斯扩散回填（含 1px AA 圈）。眼睛/嘴/口腔红为大色块由面积上限排除，
   描边带触碰半透明边由围合判定排除——只清散点，不误伤五官与描边；
4. `fix_patrick_outline`：外轮廓 10px 带内强红像素（权重=红度×低绿度）向近黑 `(20,18,16)` 均匀混合——
   描边核心 (227,85,70) 全量回色、皮肤粉不动、口腔红在带外不受影响。
（顺序原因：先 blue 再 blotches，否则 blotches 级联留橄榄 AA 圈、blue 空转；skin 在 outline **之前**，
轮廓带内的红点先回肤色、不留近黑残点，描边核心线面积大不受 skin 影响。参数即 PR #14/#16 固化值 + 十代新增。）

### 4.3a 海绵宝宝固定调色（十一代新增，G3，`sb_palette.py`，单元贴入前执行）

对症样张对比结论"淡黄绿、气孔发荧光绿、外缘浅绿描边晕、眼球/衬衫发灰"。四步、固定参数、
颜色锚点全部采样自样张海绵宝宝区域：

1. 身体淡黄绿 (≈240,240,110) → 样张官黄 (≈240,224,64)：掩膜内 `G -= 0.12*(G-B)`、`B *= 0.55`；

   **根因修正**：十代配方 §2 记为"LoRA 浅绿描边漂移"的观感，实测为 RMBG 灰白 AA 边缘贴深绿
   背景的呈色——回描边黑即消除，兼得样张的粗描边观感；
4. 灰白（眼球/衬衫，S<0.12 且 200≤V≤246）→ 纯白 250。

## 7. 复刻模式（十三代，issue #27：直接复刻样张）

触发条件：验收对象=样张本身（“密集群像+共同焦点”这类指定构图），而不是“同风格自由新场景”。
此模式与 §4.2 场景表模式并存，共用单元管线/抠图/硬口径，只替换“构图来源”。

### 7.1 与场景表模式的差异（样张权威口径）

| 项 | 场景表模式（§4.2） | 复刻模式（本节） |
|---|---|---|

| z 序 | 后排→前排两层 | 样张显式 z 序（本代：背景鱼→珊迪→派大星→章鱼哥→地图→蟹老板→海绵宝宝→黄手/铲→前排鱼→小蜗） |

| C5 尺寸档/50% 线 | 强制 | 不适用（样张角色簇顶部即在 50% 线上方；实测为准） |

| 背景 | bg-flat11 固定花纹表 | bg-flat13：花朵/场泡位置与半径按样张实测复刻 |

### 7.2 复刻配角的绘制路线（重要教训）

背景鱼/痞老板这类配角**无专属 LoRA**，底模直出 25 张（g13raw 5 角色批审）**全部风格偏出官方 2D**
（Q 版化/橡皮管风/毛茸风）。样张中它们本就是纯几何扁平卡通 → 用 `draw_cast13.py` 程序绘制
（3x 超采样 + LANCZOS，黑描边），风格 100% 可控、零伪影、可微调到样张形状。
主角六员仍走 LoRA 单元管线（SB 复用十二代短腿单元 + 硬闸C 手术）。
道具（寻宝图/宝箱/小铲/Hi! 泡泡/彩蛋泡泡/沙岛）全部程序绘制；
图上文字：地图字迹用**伪字形笔画簇**（不可读、无文字口径），样张的 “Hi!” 泡泡按样张保留描线字，
“My Leg!” 牌未复刻（见差距清单）。

### 7.3 复刻自检法（每轮必做）

`compare13.py 成品 样张裁区 前缀` → 整幅并排 + 关键区域（faces/map/helmet/gary/leftfish/egg）
2.5x 放大对照，逐区核对：叠压次序、相对位置/身高、表情、描边、皮肤红点。
迭代记录：v1 布局→v2 z 序修正（蟹老板前置地图、SB 后移）→v3 盔圈高光/粉花/配角色彩/站位→v4 配角比例微调。
审计产物：`paste-report-generation-13-*.json`（贴入比）、`audit13/`（盔圈+皮肤必检裁切）。

### 7.4 同结构变体可否量产？

可以。`STACK` 表就是全部构图状态：换单元种子（同角色不同表情/姿态）、改 tilt/相对位移 ±10%、
换地图字迹伪字形随机簇、换场泡种子，即可批量产出“同结构不同细节”的复刻变体，
硬闸（腿身比/贴入比/皮肤/描边）逐张自动复核。不可量产的是**坐标本身**——它是样张的一次性实测，
复刻另一张样张需重新走 7.1 的网格实测。

### 遮挡方法：圈层三明治（ISSUE 建议路线一为主，融合路线二的截断）
每圈 z 序（背景像素零修改）：
1. 背景（含圈远缘与圈内水体/沙面，原样）；
2. （沙滩圈）圈内接触投影：孔下半部偏左下的软暗斑（乘算 0.82）；
3. 角色单元：**坐态锚定**——腰部(裤腰/西装腰)置于 hole 中心深度（hole_cy+δ），
   胯以下截断（路线二式 cut，截断面必须落在「hole 下缘 ~ outer 下缘」的前缘带内=水下/圈内）；
4. 水圈特效：水位线=腰部深度；腰部以下 ∩ hole = 水下 → 水色回染（深水 0.24 / 浅水 0.14，
   wl+14 起 20px 滑入）；圈外下垂肢体回染 0.45（没入圈前水面）；水线泡沫只落身体两侧水面；
   身体水线边缘接触微光；前缘内沿泛水高光弧；
5. **前缘层**：`outer ∧ ¬hole ∧ y>hole_cy`（从背景本身裁出，1.2px 羽化）压回 → 前缘压住
   角色胯部与截断面 = 真实遮挡，圈远缘、圈内景物零改动；
6. （深水圈）左下压扁镜像倒影（α=0.20，高斯模糊，裁掉与邻圈重叠区）。

不变量：身体宽 ≤ hole 宽（避免跨圈遮挡冲突；黄圈被蓝圈左缘/粉圈左上缘叠压处不放前缘覆盖身体）。

## 十五代 · 样张为唯一标准：分区重绘（B 路线）+ 多边形贴回（ISSUE #31）

**验收标准变更**：以 `review/reference/swim-ref.jpg`（比奇堡群鱼度假样张）为**唯一**标准，
十四代成品作为「之前」基线。差距清单见 `delivery/batch/gap-analysis-round15.md`
（D1 入圈姿态 / D2 度假叙事 / D3 画风统一 / D4 场景氛围），本代逐项对靶。

### 路线判定：B 胜出（A/B 均有实测证据）
- **A 路线（沿用十四代单元贴合法）**：新增「全身瘫坐」白底单元试产（`gen15a.py`：
  sitting on the ground, legs stretched forward crossed at ankles, leaning back）。实测：
  ① 合格率依旧低（4 seed 出 1 可用，seed 72 多人分裂）；② SB-sit-71 腿身比竖投影 **1.71**，
  远超硬闸 C [0.55,0.75]——瘫坐单元竖投影天然偏长，还要回退到十四代的截断技巧；
  ③ 贴合法天花板不变：上身后加、光向靠 8.5% 暖混近似，样张的「画在同一张画里」的光斑
  反射、水波纹包裹、圈体投影仍然补不齐。
- **B 路线（分区 img2img + 多边形贴回，`gen15crop.py`+`paste15.py`+`compose15.py`）**：
  小规模试跑三阶段后定型——
  1. 掩膜 inpaint（`InpaintModelConditioning noise_mask=True`，鱼形掩膜）：**背景保持完美**
     （其余鱼/圈/心形/星鱼零改动），但姿态被压成「大头贴圈」（chibi pancake），三 seed 全灭；
  2. 整图重绘（`noise_mask=False`）：姿态好（seed 22 腿翘圈上）但整图色偏、场景漂移，不可用；
  3. **裁片 img2img（定型法）**：以圈为中心方形裁片（CROPS 表）→ lanczos 放大 1.7x →
     整片 img2img（denoise 0.88、cfg 5.5–6.5、30 步 dpmpp_2m karras）→ 缩回 →
     **多边形羽化贴回**（外圈椭圆∪角色多边形外扩，**扣除邻居圈椭圆**，高斯羽化 14px）。
     模型拥有完整小场景先验，「坐在圈里、腿压前缘」一次命中；样张场景 100% 像素级保留。
- **结论**：B 路线的画风/光向天然统一（同图同模型同光），姿态天花板最高，且场景氛围元素
  （夕阳反光/星鱼/心形/ZZ/鱼影）零损失——A/B 对比图 `delivery/batch/ab-compare-round15.png`。
